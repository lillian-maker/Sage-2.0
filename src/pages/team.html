WHAT MAKES AN AI EMPLOYEE PROFESSIONAL

专业性，落实在判断的方法与标准里

Agent、Skills 与 MCP 是实现手段。对业务而言，更重要的是它们支持什么判断、留下什么依据。

01 / AGENT

职责决定问题的问法

专业岗位不仅有角色名称，还要明确要解决的决策、允许使用的资料、必须检查的约束与交付标准。机会研究先问证据是否成立；商业判断再问成立后是否值得投入。

每个岗位的能力，都要在具体任务中接受验收，而不只靠一个角色名称。

02 / SKILLS

方法可复用，结果才稳定

Skills 将可复用的分析步骤、判断规则和成果要求交给岗位。VOC 研究在归类情绪之外，还会核对样本、需求频次、现有替代方案与反证；经营分析在增长率之外，还会核对口径与约束。

每套方法都有版本、适用条件和测试样本，改进要在相同样本上验证。

03 / CONTEXT

先理解这家企业，再讨论行业经验

品牌定位、目标市场、渠道、商品结构、资金约束与历史决策共同构成业务上下文。通用行业知识无法替代这些条件；同一建议，对不同品牌可能有相反的结果。

共享上下文要保留资料来源、时间和权限，并把事实、推断与缺失信息分开，避免把过期经验当成当前事实。

04 / MCP

工具提供依据，权限另行授予

MCP 用于规范工具与数据连接。查询记录、执行计算、检索资料，让判断能够接触可核对的业务依据，而不是仅依赖模型记忆。

数据准确性、访问权限、执行授权与真实结果分别确认；改价、采购或发布，都需要你单独授权。

05 / HANDOFF

交接的是可使用的成果

每次交接都写明下一岗位需要的信息：证据来自哪里，覆盖什么范围，哪些假设未验证，什么条件下才能继续决策。

交接标准决定成果能否被复用。清晰的来源、约束与未决问题，比更多聊天记录更重要。

06 / REVIEW

复核需要不同的检查职责

复核岗位承担独立的检查职责：核对来源、计算、遗漏条件、反例和授权范围，并可以退回成果或要求补证。

重要结论还会结合外部证据、确定性校验和人工判断共同确认。

07 / CONTROL

建议与执行，分开授权

提出方案、批准方案、执行动作和确认完成，分别承担不同责任。涉及资金、公开发布或外部系统变更时，应明确负责人、预算和可撤回条件。

AI 提出建议，企业做出授权；经营目标是否实现，以真实的业务结果为准。

08 / EVALUATION

专业能力必须能被反复检验

任务验收应覆盖事实正确性、计算口径、证据充分性、约束遵守与交接可用性。版本变化后，在相同任务上重新比较，用持续的结果说明稳定性。

评估结果用于持续改进方法，让每一次升级都有据可查。

COLLABORATION WITH A REASON

让每个判断
经得起不同专业的追问

需要协作的，是相互影响的判断

当需求证据、产品可行性、利润条件与进入风险相互牵制时，分专业研究能保持各自的检查深度。汇总时不应抹平分歧，而应指出结论依赖哪些条件、缺什么证据、由谁确认。

岗位按问题组织，不是让全部员工同时运行。研究可以并行，依赖同一结论的工作则需要明确接收条件。

不需要团队的，保持简单

明确的字段校验、计算、单次检索或短文案任务，可以用规则、工具或单个岗位完成。只有增加协作能够改善覆盖范围、复核质量或交接可靠性时，才值得承担额外耗时与 Sage Credits 消耗。

Sage 按任务组建团队，用最合适的岗位组合完成工作。
