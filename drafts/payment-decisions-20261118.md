# 支付规则确认记录（2026-11-18）

来源：与产品负责人的对话确认。优先级高于 `Sage_支付PRD_2026-10-02.md` 正文；PRD 尚未同步修订。
对标对象：Qoder（qoder.com / qoder.cn）的订阅与支付功能，金额和额度数值不照搬。

## 已确认

| 编号 | 规则 | 影响的 PRD 条目 |
| --- | --- | --- |
| C01 | 等支付宝自动续费权限审核通过后，与自动续费一起上线；此前不开售 | R03、R17 |
| C02 | 订阅按月或按年，默认自动续费；到期前 1 天扣款 | R17 |
| C03 | 自动续费扣款失败：不重试、无补缴期，到期降为免费版（个人版和团队版相同） | R18（取消 3 天补缴） |
| C04 | 取消仅关闭自动续费，当前周期用到期满，不退款；周期内不支持降级 | R17、R19 |
| C05 | 手动续费和提前续费：只能续当前档位，可选按月或按年，从当前到期时间顺延，不限次数，不改变自动续费周期 | R14（新增） |
| C06 | 升级：随时可升、立即生效；按旧套餐剩余时间折算抵扣，用户只付差额，不产生退款 | R19（保持现有算法） |
| C07 | 周期结束时间：新购从付款时刻加一个自然月（或一年）后顺延到次日零点；续费从上一周期结束时间加一个自然月的同日零点；月末取当月最后一天；按北京时间 | R20、D03 |
| C08 | 点数包有效期自购买日起 1 个月，个人和团队共享点数包相同；仅有生效付费订阅的账户可买；可叠加，各自独立到期 | R05、R09、R11 |
| C09 | 在线退款：订阅付款后 24 小时内且未使用任何点数可全额退；点数包按未用比例退；符合条件的由系统原路退回 | R25–R27、D06 |
| C10 | 官网提供个人版、团队版、企业版三个入口；个人版和团队版在线购买，企业版走采购咨询 | R04、R29 |
| C11 | 各档每月点数、点数包规格、成本换算比例由产品负责人提供；提供前不发布商品 | D02、D11 |

## 仍待产品负责人提供

- 各档每月点数、团队版每席点数、点数包规格与价格、年价、团队版单价。
- 任务成本换算成点数的比例与汇率；由哪个任务服务上报用量。
- 套餐到期后剩余点数可用的“基础任务”范围；各档权益清单。
- 获批的中英文购买条款、自动续费条款和退款条款。
- 支付宝自动扣款产品的审核结果与具体产品名称（决定签约和扣款接口）。


## 2026-11-18 补充确认（PRD 审计中提出的 7 个问题）

- C12 超过 24 小时：月付不退；年付可退未开始的完整服务月，手动提前续的未开始下一期可全额退。
- C13 24 小时全额退适用于新购、自动续费扣款、手动续费、升级补差价。Qoder 文档未按订单类型区分。
- C14 团队减少名额不退款，只影响下一期续费数量。
- C15 部门额度和个人额度第一批随团队版上线（取代原默认处理 P04）。
- C16 企业版规则参考 Qoder：保留既有 Enterprise 规则，官网只做咨询，签约后后台开通。
- C17 点数包有效期：付款时刻加一个自然月后顺延到次日北京时间零点。
- C18 续费提醒发送失败：照常扣款并报警。

## 2026-11-19 变更

- C19 放弃自动续费（取代 C01 及与自动扣款相关的 C05、C18、P09）。依据：支付宝“商家扣款”准入条件（https://ideservice.alipay.com/cms/site/0j06gs，2026-03-28 升级后的版本）要求企业注册资本≥2000 万元，且近半年每月主动支付用户数≥300 人；旧版“周期扣款”不再接受新接入。订阅只按一个月或一年的固定期限出售，到期不自动扣款，可手动续费。后端自动续费能力保留但不开启（`BILLING_RENEWAL_CHARGING_ENABLED` 保持关闭，不配置签约产品）。
