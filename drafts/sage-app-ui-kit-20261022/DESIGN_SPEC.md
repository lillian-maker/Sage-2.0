# Sage 产品设计规范

本规范收敛最新浅蓝版与纯黑版。设计目标是：先识别岗位，再记住同事，最后自然进入协作。品牌感来自浅蓝、清晰层级、稳定的人物身份与克制的组件，而非额外装饰。

本交付包包括 38 类可复用 Web 组件，接入与业务边界见 [README](README.md)。当前 53 人资产为既有 512×512 WebP 的原字节副本，无本轮修图或转码；原始 PNG 摘要与 WebP 摘要分别保存在 [资产清单](assets/avatars/manifest.json)。使命只为 8 位视觉样例审阅，其余 45 位在 employees.js 中为 null，接入前须补齐正式内容。

配套：[可视化规范页](index.html) · [设计变量](tokens.json) · [32 个 SVG 图标](icons.svg) · [规范总览](visuals/design-system-overview.png)。

## 1. 依据与适用范围

| 层级 | 规则 | 使用方式 |
| --- | --- | --- |
| 用户已确认 | 浅蓝侧栏、白色内容；深色主背景纯黑；浅蓝按钮深色文字；最新人物身份；职位优先；使命常规字重完整展示；头像进入资料；卡片只留“对话” | 后续设计必须保留 |
| 当前视觉稿基线 | 1600×1024 桌面画布；224px 侧栏；卡片、头像、菜单等尺寸 | 本规范明确列出的当前基准 |
| 本次补齐的建议 | 深色焦点环、语义反馈色、加载与错误状态、响应式断点、资料/对话内容规则、触控命中区 | 待本规范整体确认；不能当作已上线行为 |

来源为 [最新本地原型](app.html?view=experts)与[评审记录的最新章节](README.md#design-baseline)。历史深墨蓝背景、闪电专家图标、方形对话按钮、账号菜单“设置”等已被覆盖。

本规范页可以演示主题、按钮、资料弹窗与受限入口。账号、用量、版本和对话为设计样例；真实 App 接入不在本次范围。

## 2. 视觉方向与品牌

- **清爽、可信、有精神**：浅色用白与浅蓝分层，深色用黑与中性灰分层；蓝色只承担选中和行动强调。
- **身份稳定**：人物五官、发型与轮廓先建立识别；岗位装饰只补充强特征，不为每人添加道具。
- **信息可扫读**：职位 > 姓名 > 使命 > 工作风格。使命用一段完整自然语言，不堆加粗、角标或多层标签。
- **操作有主次**：卡片只有一个主动作；页面标题区不叠加营销横幅、统计看板或无意义数字。

### Logo

直接使用正式曲面 S＋星芒＋完整 Sage SVG，不重新描字、不变形、不加金属材质或发光。浅底用深字版，深底用浅字版。产品侧栏组合尺寸 **112×49px**，受限空间可用 **96×42px**；四周至少留 12px 无干扰区域。品牌图形不是通用“专家”图标。

资源：[浅底组合](assets/brand/sage-logo-product.svg)、[深底组合](assets/brand/sage-logo-dark.svg)、[独立图形](assets/brand/sage-brand-mark.svg)。12px 安全区为本次建议；尺寸沿用现有资产。

## 4. 字体与字号

中文优先系统字体 **PingFang SC**，英文及数字沿用系统无衬线。完整回退：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。不额外下载字体；Windows 回退为本次补充建议。使用 400、500、600 三档字重；使命不加粗。

| 样式 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 28 / 36 | 600 | 专家、知识中心等 |
| 弹窗标题 | 24 / 32 | 600 | 登录、通用弹窗 |
| 分区标题 | 20 / 28 | 600 | 资料分区、规范分节 |
| 职位标题 | 18 / 27 | 600 | 员工卡片最突出文字 |
| 员工姓名 | 15 / 23 | 400 | 与职位拉开一档 |
| 账号菜单 | 15 / 24 | 500 | 语言、主题、帮助、关于、退出 |
| 正文/使命 | 14 / 24 | 400 | 完整职责与对话正文 |
| 按钮 | 14 / 20 | 500 | 对话、保存等 |
| 表单/筛选 | 13 / 20 | 400，选中 600 | 搜索、筛选项 |
| 辅助说明 | 12 / 18 | 400 | 提示、次级值 |
| 风格标签 | 11 / 16 | 400 | 仅短标签，不承载核心信息 |

当前关于弹窗的产品名特例 **26px / 600**。界面单位均为逻辑 px，不按 2× PNG 像素数交付。计数/用量建议等宽数字。正文不低于 14px；辅助信息不滥用低对比浅灰。中英文不刻意增加字距，长职位允许自然换行。

## 5. 间距、圆角与层级

**4px 基础网格**：4、8、12、16、20、24、28、32、40、48、64。图文间距 8；菜单图文 12；卡片间距 16；卡片内边距 20；页面左右 32。

| 元素 | 圆角 | 描边/层级 |
| --- | --- | --- |
| 输入、筛选 | 8px | 1px 控件边框 |
| 导航选中块 | 11px | 填色区分 |
| 员工头像 | 12px | 中性边缘，不叠加彩色描边 |
| 员工卡片 | 13px | 1px 卡片边框；默认无重阴影 |
| 账号浮层 | 18px | 1px 边框＋轻阴影 |
| 关于弹窗 | 22px | 1px 边框＋遮罩 |
| 主动作 | 胶囊 | 高 40px 时半径 20px |

层级顺序：页面 < 悬停提示 < 账号菜单 < 子菜单 < 模态遮罩/弹窗。不要用阴影同时强调所有卡片。浅色浮层参考阴影 `0 16px 44px #1C35452B, 0 2px 6px #1C35450D`；深色用黑色阴影与清晰边框。

## 6. 按钮规范

| 类型 | 尺寸 | 样式与用途 |
| --- | --- | --- |
| 对话 | 高 40px；卡片内满宽；图文间距 8px | 轻蓝胶囊；文字“对话”；17px 气泡图标 |
| 页面主动作 | 高 40–42px；左右 20px | 品牌浅蓝；用于登录/注册、保存；同一区域一个主动作 |
| 次按钮 | 高 40px；左右 16px；8px 圆角 | 透明底＋控件边框；取消、返回 |
| 文字按钮 | 可见文字 14px；命中区至少 40px 高 | 详情、重试；颜色用信息色，不能只换光标 |
| 图标按钮 | 20px 图形；40×40px 命中区 | 必须有可访问名称；触控目标建议 44×44px |
| 受限入口 | 当前新建专家可见高 36px；扩展命中区至 40px | 灰态；响应解释而非创建 |

**状态**：对话默认/悬停/按下用配色表；登录/保存默认品牌蓝 `#AEC8E2`，浅色悬停 `#9FBFDE`、深色悬停 `#BED5EB`（`brandAction` / `brandActionHover`）；键盘焦点为 2px `focus`、向外偏移 3px；按下最多下沉 1px。加载时保留宽高与动作词，例如“发送中”，加小转圈并阻止重复提交；真正禁用用原生 disabled，无悬停反馈。加载、错误与扩展命中区是本次补齐建议。

“新建专家”是特例：创建能力不可用，但说明入口可交互，不使用会阻断事件的原生 disabled。鼠标点击/Enter/Space 均展示锚定说明，标题“暂未开放”，正文“可先与内置专家对话。”；气泡宽 246px、内边距 16px、圆角 10px。支持 Esc/外部点击关闭；不把“暂未开放”常驻到按钮旁。

卡片不增加“查看资料”按钮，不把“对话”改回“开始对话”，不单独右对齐一个小按钮而让卡片底部大面积留空。深色主题主按钮文字也必须保持 `#14243A`，不能自动反白。

## 8. 核心组件

### 员工卡片

结构固定为：**头像＋职位/姓名 → 完整使命 → 工作风格 → 满宽对话**。

- 最小高度 316px；内边距 20px；边框 1px；圆角 13px。内容变长时增高，不裁切。
- 头像 88×88px；与身份文字间距 12px；保留原图，不再生成或磨皮。
- 职位 18px/600，姓名 15px/400；岗位较长可换行，不能缩小到比姓名更弱。
- 使命 14px/24px/400；顶部 16px、底部 12px；不添加“核心使命”标题，不用省略号。
- 风格标签间距 6px，内边距 5px 9px，可换行。标签是风格，不当作真实能力证据。
- 同一行以最高卡片决定行高，按钮底边对齐。不要为凑行数增加废话；不把长职责压缩成过小字号。
- 点击头像进入资料；悬停/键盘聚焦给出边缘反馈与“查看××资料”的可访问名称。卡片其余区域不默认变成第二个入口。
- 不出现管理身份/岗位专家角标；类别只放筛选栏。

### 搜索与筛选

搜索宽 320px、高 38px、内边距 12px、图文间距 10px、圆角 8px。文案严格使用 **“搜索名称、岗位或使命”**。须有独立可访问名称，不能只靠 placeholder。清空图标有至少 40px 命中区。输入边框、悬停、焦点、清空、空结果为本次补齐状态。

筛选为“全部 53 / 管理身份 3 / 岗位专家 50”，计数以实际数据为准。选中用轻蓝底＋600 字重；未选中透明。筛选后保留搜索词。空结果显示“未找到匹配的专家”及清除筛选入口；不能显示错误头像或伪造员工。

### 侧栏与账号

侧栏宽 224px；导航行高 44px；图标 20px；图文间距 12px。一级导航名称沿用当前产品，不为借鉴竞品而添加未支持功能。

未登录：语言 → 主题 → 帮助中心 → 分隔 → 登录说明 → **登录 / 注册**。工具行 40px/14px/500；登录按钮高 42px。

已登录：32px 账号头像＋姓名/套餐＋升级入口。展开账号浮层宽 312px、内边距 12px、圆角 18px；行高 44px。顶部姓名 15px/600，邮箱 12px，资料行**无右箭头**。菜单顺序为 **语言、主题、帮助中心、关于 Sage、退出登录**；主文字 15px/500，二级值 12px/400；语言/主题保留子菜单箭头；**删除设置**。退出之前设分隔线。

未接入用量显示“用量待同步”，不画伪造进度或借用竞品额度。原型中的示例用户不是正式账号信息。

### 关于 Sage

页面中央模态窗 560px 宽、最小高 480px，内边距 42px 40px 28px；小窗口可缩至可用宽减 32px。原始品牌图形 72×93px，名称 26px/600。版本、构建、发布日期未知时用 `—`，检查更新禁用；不沿用 Accio 数值。

浅色背景白、边框 `#D7E0E9`；深色背景 `#1B1B1F`、边框 `#3A3A40`；保留关闭控件、底部分隔及版权。打开时关闭账号菜单、聚焦弹窗、阻止背景交互；Esc/关闭/遮罩关闭后焦点回到触发入口。

### 表单与反馈（补齐建议）

输入默认高 42px；标签 13px/500，与输入间距 8px；帮助/错误 12px/18px，与输入间距 6px；组间距 20px。错误保留用户输入，并在字段旁说明具体原因，不仅变红。Toast 仅用于短暂、非关键反馈；需要处理的问题使用就地提示，不自动消失。

### 资料页与对话页（内容层级建议）

资料页首屏保留头像、岗位、姓名与“对话”；下方按“负责事项 / 工作方式 / 适合交办”分组，完整职责在资料正文中展示。不要新增无依据的技能评分、在线状态或认证徽章。

对话页头部固定显示当前员工头像、岗位、姓名；正文维持 14px/24px，消息内容建议最大宽 760px；品牌浅蓝用于用户输入与行动强调，员工长回复用中性背景分段。输入区将输入、附件和发送分层；失败保留草稿并提供重试；进行中明确显示“处理中”。不以头像气质暗示真实能力或已完成任务。

## 9. 布局与响应式

用户已选定四列专家页，交付包只保留这一版。设计画布为 **1600×1024**：侧栏 224px，主内容左右各 32px，卡片间距 16px；四列卡片约 316px 宽。8 个样例使命在该画布实测为 3 行；不能推广成 53 人必然等长。

以下为本次建议，尚未在实际 App 验证：

| 可用窗口宽度 | 建议 |
| --- | --- |
| ≥1280px | 四列；宽屏可设内容最大宽 1728px |
| 960–1279px | 两列 |
| <960px | 收起侧栏，页面边距 24px；工具栏可分行 |
| <640px | 单列，页面边距 16px；搜索满宽 |

桌面四列不提供列数切换。较窄桌面卡片随窗口收缩，岗位与使命允许增加行数；中文使命完整可见，不能通过裁字维持固定高度。响应式需结合实际 App 侧栏、缩放与长岗位复核，小窗口使用两列或单列。

## 10. 人物资产与辨识规则

采用 [当前 53 人素材](avatars.html)和 manifest，姓名与岗位按稳定员工 ID 绑定。天时保留现有面部身份及正式灰西装/浅蓝衬衫；知人女性、砺器男性、解忧女性；绘影无耳机。安心可用客服耳麦等强岗位记忆元素；不强行为每人添加装备。

统一浅中性灰背景、蓝灰白服装、均匀自然肤色；不要蓝白交替背景、油亮反光、斑驳光影、过度修容或刻意歪头。脸型、发型、发际线、眉眼、肩线和神态要能拉开身份；不能只换衣服或用半身手势替代头像辨识。

| 使用场景 | 显示尺寸 | 检查 |
| --- | --- | --- |
| 对话列表/紧凑身份 | 32px | 是否仍可定位同一员工 |
| 会话页头/最近同事 | 48px | 头发轮廓、脸型、配饰有差异 |
| 资料索引 | 64px | 匿名成组对比，避免相似五官 |
| 目录卡片 | 88px | 现有标准裁切，不改变面部比例 |
| 资料页 | 112–128px | 与小尺寸是同一原资产 |

32/48/64px 匿名识别是**后续验收方法**；本规范页仅提供尺寸对照，不宣称 53 人已通过用户识别测试。头像只承载身份，不由相貌推断能力、可信度或绩效。

## 11. 交互与可访问性验收

- 正文/按钮文字目标对比度 ≥4.5:1；大字 ≥3:1；关键控件边界与焦点目标 ≥3:1。禁用项另算，不能降低正文可读性来迁就禁用视觉。
- 默认桌面命中区至少 40×40px，触控建议 44×44px；小图形的扩展命中区不得相互覆盖。
- 所有可操作项可用 Tab 定位，Enter/Space 激活；菜单建议支持方向键与 Esc。焦点顺序按视觉阅读顺序，不隐藏焦点环。
- 悬停 140ms、按下 100ms；浮层进入 180ms、退出 120ms，位移 ≤4px；不使用 `transition: all`。减少动态效果时关闭位移/过渡。
- 模态窗限制焦点在内部，关闭后返回入口；普通气泡不抢夺输入焦点。错误、加载与成功消息应可被辅助技术读出。
- 不把 hover 当成唯一信息入口，不把颜色当成唯一状态区分，不制造虚假在线、完成或已连接状态。
